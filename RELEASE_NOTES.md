A free, local-first study workspace with 250 DSA problems, C++17 and Python solutions, 68 lessons, LLD/HLD case studies, modern AI, Google/Microsoft preparation, and three themes.

[Open the website](https://23anish.github.io/Switch/).

Download **Switch-macOS.zip** below, unzip it, and drag **Switch.app** into Applications. Supports Apple Silicon and Intel on macOS 12+. This build is ad-hoc signed, not Apple notarized; if macOS blocks it, review the source and use System Settings → Privacy & Security → Open Anyway.

C++ execution requires Apple Command Line Tools; Python requires Python 3. JavaScript works without additional tools. The website supports C++/Python editing and solutions; their execution runs locally in the Mac app. Run only code you trust.

Included tests: 506 cases pass for each of C++, Python, and JavaScript. These cover examples and selected boundaries, not an exhaustive judge. Progress is stored locally, with profiles and JSON backup/transfer.

The attached SHA256SUMS.txt records the checksum of this package. The Mac package is built from this release’s source by the repository’s visible GitHub Actions workflow.
